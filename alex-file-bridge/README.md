# Alex File Bridge

Statische, sicherheitsorientierte Datei-Webseite.

## Struktur

- `index.html` = Website
- `files/` = Dateien, die öffentlich verlinkt werden sollen
- Für Dateien in `files/` verwendet die Seite die echten GitHub-Download-URLs.

## GitHub Pages

Im Repository muss GitHub Pages für diesen Bereich veröffentlicht werden. Am saubersten ist eine Pages-Deployment-Workflow-Konfiguration; alternativ kann die Seite nach Aktivierung der Pages-Funktion veröffentlicht werden.

## Wichtig

GitHub Pages/GitHub-Repositories sind **kein unbegrenzter Dateispeicher**. Für große ZIPs und Videos ist ein dedizierter Objektspeicher besser. Diese Seite ist deshalb bewusst als sichere Frontend-/Index-Seite angelegt.
